# Biases and countermeasures

Knowing a bias exists does not correct it. Only procedure corrects it. An AI agent is not immune.

| Bias | How it shows up | Countermeasure |
|---|---|---|
| Confirmation | Reading only what supports the favourite | Write first what would refute it |
| Anchoring | The first reading or an agent's report dominates | Judge before reading others'; estimate from scratch before seeing the old one |
| Blurred data first | The reading of an ambiguous item contaminates the next ones | Mark it provisional; reread from scratch with better data |
| Incrementalism | One negative a day, nothing changes | Periodic from-scratch review |
| Retracted evidence | The impression survives the fact that fell | `estado <id> retratado` and reassess linked items (`ver <id>`) |
| Centralized direction | "Every detail was intentional" | H-artefact in the matrix |
| Similarity | A type-X problem "calls for" a type-X solution | Ask whether it must be the same type |
| Narrative | A coherent story feels true | P(scenario) = product of the steps |
| Acceptance by coherence | Data accepted because it closes the story | Grade before fitting |
| Explaining by naming | "It's a case of X" as an explanation | Demand the test that separates X from the rivals |
| Small numbers | Little data, all consistent | Confidence limited by size |
| Vividness | "Someone swore they saw it" | Grade C until there is verifiable material |
| Data immersion | "I'll look until I see something" | Hypothesis written before looking |
| Method orientation | Carrying on because the tool is ready | Every tool answers a question |
| Base rate | Forgetting how many such attempts failed | Prior from the outside view |
| Availability | An elaborate hypothesis feels likely | Work invested is not evidence |
| Hindsight | "It was obvious" afterwards | `--previsao` in the `teste` |
| Sunk cost | Insisting because a lot was spent | Stopping rule written at the start |
| More information | Gathering more material to be sure | Classify the expected information (`hipoteses.md`) |
| Cascade | The coordinator's hypothesis seeps into the verifier | Verifier without the verdict, with decoys |
| Snowball | Instrument tuned on the hypothesis' material | Instrument and corpus from outside the case |
| Planning | Deadline estimated on paper | Rate measured where it will run |
| Noise | The same agent judges differently in another order | Independent judgments and the average |
| Drowning | Too much material, plan lost | Back to the `mapa`; declare the mode |
| Forgetting the path | A conclusion rediscovered as new; a correction erasing why | Every line as a branch; `ficha`/`trilha` before acting |

## Frequent fallacies

Affirming the consequent; correlation read as causation; false dilemma (without H-nothing and H-mundane);
appeal to ignorance; Texas sharpshooter (target drawn around the shots); straw man of the rival; transposed
conditional; multiplying dependent evidence; regression to the mean read as an effect.

## The opposite bias of each technique

After using the technique, one counterweight line:

| Technique | Opposite bias |
|---|---|
| Checking premises | Blaming the situation too much |
| Checking sources | Under-confidence; endless search |
| Indicators | Over-confidence, overfitting |
| ACH | Incoherent probabilities (summing to 1 fixes it, if the rivals are exclusive) |
| Reading for meaning | Spurious semantic connection: a broad theme links everything; demand a prediction the rival does not make |
| Candidate connections | A collection of imaginary associations: record only the promising one, reject with a reason |
| Devil's advocate; "what if?" | Forgetting the base rate |
| Team A/B | Polarization |

Sometimes the best technique is none: a technique does not replace measurement.

## Symptoms of a sick investigation

Frozen method; endless survey; never finishes; one person with one hypothesis; a theory that can never be
falsified; an outdated map. Use them as self-diagnosis in the from-scratch review.
