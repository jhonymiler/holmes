# F4–F6 — Control, validation and verification

## Control: measured power, never planted data

Declaring `--control-type real` is not seeing the control pass: without `result ... --control-ok yes`, the
result comes out "control not confirmed" and supports no conclusion. An `--exploratory` test never supports one.

Planting data generated by the function itself and seeing whether it finds it only proves the comparator:
f(x) == f(x). Internal consistency has the same defect. Whoever writes the test already knows the answer.

Prefer, in this order:

1. **Real data already published:** an official vector, a value someone else published, or an answer the case
   itself already has.
2. **Two independent implementations**, made at different times.
3. **Observed against predicted rate on real data:** loosen the criterion until chance hits appear and compare
   with the expected rate. It proves the whole path runs on real data.
4. **Counting what the test did:** the number of candidates actually generated.
5. **Sabotage:** plant a defect in the code, not a datum, and require the control to complain. A control that
   survives sabotage is decoration. A defect no control sees is a serious finding: declare it.

Declare the negative with the control's power ("catches k of m sabotages") and what remained blind.
"Control: OK" declares nothing.

Record the instrument with `instrument <path> "<name>"`. If it changes, the old negatives become TO REVALIDATE.

## Criteria for accepting a solution

Answer one by one: valid / invalid / indeterminate.

1. **No choice in the middle.** Method and parameters applied mechanically.
2. **Double validity:** the result makes sense and the method was applied precisely.
3. **Not chance:** P(chance) computed over the space actually walked.
4. **Reproduction:** someone else, with only the method, reaches the same result.
5. **Length:** a result long enough not to be a coincidence.
6. **Small errors** and, if any, with a single cause.
7. **No rearranging** after selecting.

## Against fine-tuning

- **Control with the same freedom:** apply the same procedure to material without a message. If it also
  "speaks", the rule has no content.
- **Variations:** perturb each arbitrary parameter. If almost every variation makes it worse, the parameters
  were fitted to the data.
- Agreement that is too perfect suggests iterative fitting.
- **Prediction on unused data:** a rule taken from one part must work on the rest.

## Discrepancies

List every discrepancy between candidate and evidence, including expected absences. Each one needs an
explanation with independent evidence. One without an explanation → inconclusive. Two or more → likely
exclusion. "Could" and "is consistent with" are not evidence.

## Level of the proposition

| Level | Proposition |
|---|---|
| Operation | This procedure produces this result |
| Source | This is the true value or document |
| Activity | Whoever produced the material intended this reading |
| Resolution | This answers the case's objective |

A high LR at one level does not climb to the one above.

## Verification (F6)

- Whoever judges did not write the test. The verifier receives data, criterion and candidates with 1–2 decoys,
  without knowing which is the suspect.
- Reproduction by an agent without the history, with only the written recipe.
- Disagreement: complete basis and a fresh agent. Never negotiate the verdict.

## Third-party results

1. Look for a retraction before adopting.
2. Which acceptance criterion did the author use? Compute chance with their number of attempts.
3. Reproducing a published file proves it is coherent, not that it is the solution.
4. Date the publication.

## Finding checklist (yes / no / debatable)

1. Propositions written before the result, still the same?
2. Level declared, and does the criterion speak to that level?
3. Prediction recorded in the `test`?
4. FPR and sensitivity measured; expected alarms far below 1?
5. Control with measured power in this run?
6. Champion compared with the maximum under noise?
7. Discrepancies explained with independent evidence?
8. Fine traces reproduce in every version?
9. Reading recorded before the references?
10. Sources indexed and with an origin?
11. Blind verifier agreed; reproduction matched?
12. Conclusion on the scales of `scales.md`?
13. Criteria 1–7 and the tests against fine-tuning done?
